Build your Asana export

Choose what to capture, then copy the command into your terminal. The command runs on your computer. This page makes no network requests and stores no settings.

1. Destination & access

OAuth currently uses your own app registration. Shared Kit sign-in is not yet hosted. Never put a token in the generated command.

2. Capture

Core capture always includes accessible projects, tasks, their relationships, people, teams, tags and custom fields. Embedded references may remain even when a separate category is omitted.

These controls select implemented collectors. Messages/inbox, trash, rules, forms, dashboards, audit logs, app settings and prior revisions need additional adapters.

3. Remote copy & repetition

Configure the remote with rclone first. Each completed archive gets its own destination and a byte verification pass. This can incur download traffic.

Runs never overlap. If collection plus transfer takes longer than the requested interval, the next run starts after completion. Keep the process running. Failure stops the loop and retains its files.
